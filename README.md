# HandSign3D
Proyecto para titulación de Ingeniería civil en computación e informática, es una aplicación de realidad mixta que permite reconocer señaleticas típicas del gobierno regional chileno e interpretarlas a lenguaje de señas chileno (LSCh), utilizando Redes Neuronales Convolucionales (CNN) y Reconocimiento de carácteres (OCR).
## Instalación
- Descargar archivo apk desde el apartado de [releases](https://github.com/RaizAwA/LSChXR/releases).
- Dentro de Meta Quest 3/3S, habilitar instalación de aplicaciones de orígenes desconocidos, referirse a este [link](https://www.meta.com/es-es/help/quest/291654372573077/) si se desconoce.
- Instalar archivo apk dentro de Meta Quest 3/3s.
- Habilitar permisos de aplicación dentro de Meta en Configuración -> Privacidad y Seguridad -> Aplicaciones instaladas -> HandSign3D -> Activar todos los permisos.
- La aplicación se encontrará en el Menu de meta -> Icono de lista ubicado a la izquierda -> Orígenes desconocidos.
## Dependencias de desarrollo
### Instalar unity
Unity Version 6000.3.11f1, con soporte para dev de android
### Instalar Dependencias (Instaladas desde el packet manager de Unity)
- Sentis
- Unity OpenXR META (com.unity.xr.meta-openxr)
